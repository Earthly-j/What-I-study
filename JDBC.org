** 2\. JDBCノ動作原理 :drill:
:PROPERTIES:
:ID:       406BE30F-2101-4881-9FBF-7FE3BA3D9511
:END:

JDBCガ特定ノ databaseニ依存セズニ済ムノハ、[JDBC APIガ interfaceヲ基盤トシ、多態性ヲ利用シテイル] タメデス。

Application ↔ JDBC API(java.sql) ↔ JDBC driver(.jar) ↔ Database
└──────── DBMSニ依存シナイ領域 ────────┘ └─ DBMSニ依存スル領域 ─┘

| 構成要素             | 説明                                                                                                                                                          |
|---------------------+---------------------------------------------------------------------------------------------------------------------------------------------------------------|
| JDBC API (java.sql) | 開発者ガ利用スル[interface]ヲ提供 → 変更ガナイ限リ、 application側ノ修正モ不要                                                                                         |
| JDBC driver         | JDBC APIノ interfaceヲ [実装（implements）シタ] class。jar形式ノ圧縮 fileトシテ提供サレ、DBMS各社ノウェブサイトカラ downloadデキマス。[特定ノDBニ依存スル code]デ構成サレテイマス |
