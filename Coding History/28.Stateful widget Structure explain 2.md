Constructor
-----------

```
const Bird({
    super.key,
    this.color = const Color(0xFFFFE306),
    this.child,
  });
``````
super.key,
```

**Parent Initialization**Passes the `key` argument up to the `StatefulWidget`'s constructor.

```
this.color = const Color(0xFFFFE306),
```

**Parameter & Initialization** Accepts an optional `color` and assigns it to the `this.color` field. The `=` provides a **default value** **if no color is specified.**

```
this.child,
```

**Parameter & Initialization**Accepts an optional `child` and assigns it to the `this.child` field. It defaults to `null` because the field is nullable (`Widget?`).

```
this.color = const Color(0xFFFFE306),
this.child,
final Color color;
final Widget? child;
```

two parts **must always be in sync** in the logic of a Dart class,

```
final Color color;
```

**Required** to be set in the constructor.

```
final Widget? child;
```

**Optional** to be set in the constructor, but included to allow the user to provide a value.

`setState` method
-----------------

```
setState(() { _size += 0.1; });
```

`setState` it only cares that **the data has changed. so inside it need to** add Function () {}

**anonymous function** (a callback) like `()` or `() =>` inside `setState()` instead of just calling a **normal named function**.

**type is** `**VoidCallback**` (because it returns nothing and takes no arguments).
