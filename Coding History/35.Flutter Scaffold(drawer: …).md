Scaffold(drawer: …)
-------------------

**drawer** is a Panel displayed on the left side of the **body** (If **textDirection = TextDirection.ltr**). It is usually hidden on mobile devices, so you need to swipe left to right to make it appear.o

Scaffold(endDrawer: …)
----------------------

This is the optional second drawer that slides in from the **end** (right side in LTR languages) of the screen.

![captionless image](https://miro.medium.com/v2/resize:fit:456/format:webp/1*Qdkie-AfdTl1U1zccfA0Jw.gif)

Scaffold(drawerScrimColor: …)
-----------------------------

This defines the color of the barrier that covers the rest of the screen when the drawer is open.

![captionless image](https://miro.medium.com/v2/resize:fit:1400/format:webp/1*z7vTJ9XwaJRzxNWOUoGS4w.gif)

Scaffold(`rawerEnableOpenDragGesture`: …)
-----------------------------------------

Takes a `**bool**`. If set to `**true**` (the default), users can swipe from the edge of the screen to open the drawer. If `**false**`, the drawer can only be opened by tapping the menu icon (usually a hamburger icon).

> `DragStartBehavior.start` makes the drag animation smoother, while `DragStartBehavior.down` makes it feel more reactive by starting the drag at the first down event detected.

Scaffold(onDrawerChanged: …)
----------------------------

This function is called every time the `**drawer**`(left side) opens or closes. The boolean value passed to the function indicates the new state: `true` for open, `false` for closed.

![captionless image](https://miro.medium.com/v2/resize:fit:1400/format:webp/1*B8ophS4WvUpydAmMhJo0xQ.gif)

Scaffold(drawerEdgeDragWidth: …)
--------------------------------

`**drawerEdgeDragWidth**`: Takes a `**double?**` (a number). This specifies how wide the area is on the edge of the screen where the drag gesture will be recognized.

![captionless image](https://miro.medium.com/v2/resize:fit:1400/format:webp/1*TkmG9wBGIPOK47NL3JX54Q.gif)
