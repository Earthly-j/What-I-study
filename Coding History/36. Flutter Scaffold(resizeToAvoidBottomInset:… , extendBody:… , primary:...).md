Scaffold(resizeToAvoidBottomInset:… )
-------------------------------------

Automatically resized **to avoid intrusions** from system-generated elements at the bottom, primarily the **on-screen keyboard**.

Scaffold(extendBody:…)
----------------------

Controls whether the `body` should **extend underneath** the`bottomNavigationBar` or `BottomAppBar`.

Scaffold(`primary:... )`
------------------------

*   `**primary: false**`**:** Tell the `Scaffold` to ignore the status bar height, assuming you will handle the necessary padding manually, usually with a `SafeArea` widget applied exactly where need it.

One more thing… Scaffold(restorationId:…)
-----------------------------------------

*   **Mobile Frameworks (Flutter, iOS, Android):** This is where it’s most relevant. When a mobile OS (like iOS or Android) kills an app running in the background to free up resources, State Restoration uses the `restorationId` to ensure the user returns to the exact spot they left off.
*   **Widgets with User Input/Scroll Position:** You will commonly see this property on widgets that hold important, restorable state, such as:
*   **Text Fields (**`**EditableText**`**,** `**CupertinoSearchTextField**`**):** To restore the text content and cursor position.
*   **Scrollable Views (**`**ListView**`**,** `**CustomScrollView**`**):** To restore the exact scroll offset.
*   **Stateful Screens/Pages:** To restore a selected tab, the state of a checklist, or a counter’s value.
