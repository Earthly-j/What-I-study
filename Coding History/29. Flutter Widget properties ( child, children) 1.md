`children` Property
-------------------

The property name `**children**` (plural) is used for widgets that take a **list of widgets** and arrange them according to a specific layout model.

**Criteria:** The widget is a **layout widget** designed to position, size, or overlap a collection of sibling widgets.

*   `**Column**`Arranges widgets **vertically**.Linear layout

![captionless image](https://miro.medium.com/v2/resize:fit:684/format:webp/1*1CJovfXjRBlprPY8LWbRyA.png)

*   `**Row**`Arranges widgets **horizontally**.Linear layout

![captionless image](https://miro.medium.com/v2/resize:fit:716/format:webp/1*Ir-7SON7B0gzogkjHQWEEA.png)

*   `**Stack**`Arranges widgets to **overlap** .(overlapping) layout

![captionless image](https://miro.medium.com/v2/resize:fit:1400/format:webp/1*3nvjckjNN2MOlNtCXMjk3w.png)

*   `**Wrap**`Arranges widgets linearly, but **wraps** to the next line/row when space runs out.Flow layout

![captionless image](https://miro.medium.com/v2/resize:fit:1400/format:webp/1*SesUkTvyt7CMNfsGbOC3bw.png)![captionless image](https://miro.medium.com/v2/resize:fit:1388/format:webp/1*a7ASjOyMWG4gyUIuhf_hkQ.png)

*   `**ListView**`Arranges widgets in a single direction and allows them to be **scrollable**.
