Class and Widget difference
---------------------------

As we know Flutter is Object Oriented Programming but also it consist of full of widgets, then what is actually difference between both of thing, well in OOP **Class** is the most **fundamental concept,** on the other hand Widget is for **immutable description of a part of a user interface**

on the purpose sight _OOP_ is more like to **organize code,** model real-world entities, and enable concepts like inheritance and encapsulation. But _Widget_ more for to **describe the configuration** of an element that the Flutter framework should draw or manage.
