`body` Property
---------------

To denote the **main, primary content area** of a typical material design screen

**Criteria:** The widget (the `Scaffold`) is an entire-screen layout structure that holds multiple distinct, named sections (like an `AppBar`, `bottomNavigationBar`, `drawer`, and the main content

**Examples:**

*   Scaffold:provides the Material Design structure (app bars, drawers, floating buttons).
*   CupertinoPageScaffold: This is the Apple Human Interface Guideline equivalent of a `Scaffold`'s body.

**Why** `**body**`**?**

The name `body` is descriptive of a common UI structure: the header (`appBar`), the footer (`bottomNavigationBar`), and the main content **body**. It helps developers immediately identify the core content of a screen.

`home` Property
---------------

For the **root widget** that defines the initial screen of the entire application (

The name `home` is a navigation and routing term, signifying the **starting page** or the **root screen** of the entire application. It tells the Flutter framework which screen to display first.

**Examples:**

*   `**MaterialApp**`: The `home` property takes a `Widget` (often a `Scaffold`) that serves as the entry point or first page the user sees.
*   **Context:** It acts as the anchor for the entire navigation structure and theme of the application.

onPressed Property
------------------

Defines the **action** that occurs when a widget is tapped by the user.

**Examples:**

*   `ElevatedButton`
*   `TextButton`
*   `FloatingActionButton`
*   `GestureDetector`

`onChanged` Property
--------------------

Defines the action that occurs whenever a widget’s **value changes** due to user input.

**Examples:**

*   `TextField`
*   `Switch`
*   `Checkbox`
*   `Slider`
