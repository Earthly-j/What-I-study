Introduction
------------

A scaffold is a basic structure that provides like an app bar, a body, and a floating action button. Let's explore how it consist of !

1. appBar:
-----------

```
Scaffold(
  appBar: AppBar(
    title: Text('My App'),
  ),
)
```![captionless image](https://miro.medium.com/v2/resize:fit:1400/format:webp/1*nZsicrd-3cId9Rzci1D2oA.png)

2. body:
---------

```
Scaffold(
  body: Center(
    child: Text('Hello, Flutter!'),
  ),
)
```![captionless image](https://miro.medium.com/v2/resize:fit:946/format:webp/0*MHnvaDtewya2bsUO)![captionless image](https://miro.medium.com/v2/resize:fit:1400/format:webp/1*rY114emUdtBcAy_6PE6qfg.png)

```
