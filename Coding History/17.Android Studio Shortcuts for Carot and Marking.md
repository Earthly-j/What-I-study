Marking , commenting
--------------------

### Toggle Breakpoint:

![macOS: ⌘ + F8](https://miro.medium.com/v2/resize:fit:1064/format:webp/1*4MPGWpEFoUKcLtwQp3HUqg.gif)

To **pause the execution** of the application at a specific line of code. When run your app in debug mode

### Toggle Bookmark

![macOS: F3](https://miro.medium.com/v2/resize:fit:996/format:webp/1*I0xbk0XOTaB75do6HzGQ-w.gif)

**Mark a line of code** so we can quickly jump back to it later. It has no effect on how the application runs.
