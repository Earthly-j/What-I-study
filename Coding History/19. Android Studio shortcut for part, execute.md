Run Application:
----------------

macOS: Control + R

Debug Application:
------------------

macOS: Control + D

Running an Application
----------------------

Android Studio compiles and installs it on a connected device or emulator and then launches it. The app runs at its normal speed without any special tools attached

Debugging an Application
------------------------

Android Studio does the same thing as “run,” but it also attaches a **debugger** to the running app. The debugger is a powerful tool that allows you to pause the app’s execution at specific points called **breakpoints**
