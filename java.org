╠══════════════════════════════════════════════════════════════════════════════╣

║  │ • Must have no body (no {})                                             │ ║

║  │ • If a class contains any [abstract] method                             │ ║
║  │   the class itself must be declared abstract                            │ ║

║  ┌─ ABSTRACT CLASSES ──────────────────────────────────────────────────────┐ ║
║  │ • Cannot be instantiated                                                │ ║
║  │   Example: new Animal() → illegal                                       │ ║
║  │                                                                         │ ║
║  │ • Subclass must[implement all abstract methods]                         │ ║
║  │   or itself be declared [abstract]                                      │ ║
║  │                                                                         │ ║
║  │ • Can have zero abstract methods                                        │ ║
║  │   (useful to prevent [direct instantiation])                            │ ║
║  └─────────────────────────────────────────────────────────────────────────┘ ║
║  ┌─ LIMITATIONS ───────────────────────────────────────────────────────────┐ ║

║  │   → [Classes] and [Methods]                                             │ ║
